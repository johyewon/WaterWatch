# 면책 고지

## 이용약관 대신 면책 고지를 두는 이유

- 무료이고 계정·서버·결제·광고가 없는 앱이라 법적으로 이용약관이 꼭 필요하지 않다.
- Health Connect 권한 화면에 필요한 건 이용약관이 아니라 개인정보처리방침이다 ([privacy-policy.md](privacy-policy.md)).
- 건강 관련 앱이므로 "의료기기가 아니다"라는 고지는 둔다. 수분 섭취를 제한해야 하는 사용자가 있기 때문이다.

아래 기능이 생기면 이용약관을 따로 만든다.

- 회원가입이나 서버 저장
- 유료 기능이나 구독
- 광고
- 사용자가 올리는 콘텐츠

## 고지 문구

### 전체 (앱 안 정보 화면, 공개 페이지)

> 꽥은 수분 섭취 기록을 돕는 일반 건강 관리 앱이며 의료기기가 아닙니다.
>
> 앱이 보여주는 정보는 질병의 진단, 치료, 예방을 위한 것이 아니며 의학적 조언을 대신하지 않습니다.
>
> 신장 질환이나 심장 질환 등으로 수분 섭취를 제한받고 있거나, 임신 또는 수유 중이라면 적정 섭취량을 의사와 상의하세요.
>
> 앱에 표시되는 섭취량은 사용자가 기록한 값과 다른 앱이 Health Connect 에 기록한 값을 합산한 것입니다.

### 짧은 버전 (스토어 설명 하단)

> ※ 꽥은 의료기기가 아니며 의학적 진단이나 조언을 대신하지 않습니다. 수분 섭취를 제한받는 질환이 있다면 의사와 상의하세요.
