# 스토어 등록정보

문구는 디자인 기준으로 쓴다 (디자인 아티팩트 "물 마시기 습관 앱": `https://claude.ai/artifact/5KuyRG14hW3Sa6vbkGwZgb`). 앱 이름은 "꽥"이다. 디자인 시안에 쓰인 이름 "오늘의 물"은 앱 안 문구에서도 "꽥"으로 바꾼다.

스토어 설명과 스크린샷은 실제 앱과 맞아야 한다 (Play 메타데이터 정책). 아래 표에서 "코드"가 X 인 기능은 출시 전에 구현하거나, 구현하지 못하면 문구에서 뺀다.

## 디자인 기능과 구현 상태

| 기능 | 디자인 | 코드 |
| --- | --- | --- |
| 마신 만큼 물이 차오름, 50% 넘으면 오리가 떠오름, 100% 둥둥 | O | X |
| 오리 탭하면 꽥 소리 + 표정, 끌어서 던지기 | O | X |
| 빠른 기록 120ml / 250ml | O | 250ml 만 |
| 마신 양 직접 입력 (100~3,000ml) | O | X |
| 이전 기록 취소 | O | X |
| 하루 목표 설정 (500~4,000ml), 남은 양 표시 | O | X |
| Health Connect 연동 | 선택 (설정에서 켤 때 요청) | 필수 (기본 저장소) |
| 워치에서 기록 + 오리 | O | 기록만 (250ml) |

디자인과 다르게 정한 출시 범위

- 알림은 넣지 않는다. 디자인의 권한 안내 화면에 있는 알림 항목도 뺀다.
- 휴대폰을 기울이면 물이 출렁이는 동작은 넣지 않는다.
- Health Connect 연동은 필수다. 현재 코드와 같다.

## 짧은 설명 (80자 이내)

후보

1. 마실수록 물이 차오르고 오리가 둥실! 폰과 워치에서 한 번 탭으로 마신 물을 기록해요.
2. 꽥! 귀여운 오리와 함께 오늘의 물을 채워요. 마실수록 차오르는 물, 둥실 떠오르는 오리.
3. 물 한 잔 마실 때마다 차오르는 물, 떠오르는 오리. 워치에서도 한 번 탭으로 기록해요.

## 자세한 설명 (4,000자 이내)

```text
꽥! 오늘의 물, 얼마나 채웠나요?

꽥은 귀여운 오리와 함께 하루 물 목표를 채우는 앱이에요. 물을 마실 때마다 화면에 물이 차오르고, 오리가 그 위로 둥실 떠올라요.

🦆 마실수록 차오르는 물
기록할 때마다 화면 속 물이 조금씩 차올라요. 목표의 절반을 넘기면 오리가 둥실 떠오르고, 목표를 채우면 물 위를 둥둥 떠다녀요.

👆 오리를 톡!
오리를 누르면 꽥! 하고 반응해요. 끌어서 던질 수도 있어요.

💧 기록은 한 번 탭으로
120ml, 250ml 중에 골라 바로 기록해요. 다른 양은 직접 입력하고, 잘못 눌렀다면 바로 취소할 수 있어요.

🎯 나만의 하루 목표
500ml부터 4,000ml까지 하루 목표를 정해요. 목표까지 얼마나 남았는지 한눈에 보여줘요.

⌚ 워치에서도 오리와 함께
손목에서 바로 기록하고 오늘 얼마나 마셨는지 확인해요. 워치 화면에도 오리가 떠 있어요.

🔗 Health Connect 연동
마신 물 기록은 Health Connect에 저장돼요. 다른 건강 앱에서 기록한 물도 함께 더해지고, 꽥에서 기록한 물도 다른 앱에서 볼 수 있어요.

🔒 가입 없이, 내 기기에만
회원가입 없이 바로 써요. 기록은 내 휴대폰의 Health Connect에만 저장되고 개발자에게 전송되지 않아요.

📱 이용 환경
- 휴대폰: Android 10 이상, Health Connect 필요 (Android 13 이하는 Health Connect 앱 설치)
- 워치: Wear OS 3 이상, 휴대폰 앱과 함께 사용

오늘도 오리와 함께 물 한 잔, 꽥!

※ 꽥은 의료기기가 아니며 의학적 진단이나 조언을 대신하지 않아요. 수분 섭취를 제한받는 질환이 있다면 의사와 상의하세요.
```

| 앱 아이콘 | 512×512, 32비트 PNG, 1MB 이하 | 미착수 (오리) |

| 폰 스크린샷 | 2~8장, 16:9 또는 9:16, 한 변 320~3,840px | 구현 후 |
| Wear OS 스크린샷 | 1장 이상, 1:1, 최소 384×384, 기기 프레임 없이 앱 화면만 | 구현 후 |

### 스크린샷 구성안

디자인의 진행률 상태(0 → 40 → 60 → 100%)를 순서대로 보여주면 물이 차오르는 흐름이 한눈에 보인다.

폰

1. 0% 하루 시작: "물 마시면 채워지는 하루"
2. 40% 물이 차오름: "마실수록 물이 차오르고"
3. 60% 오리가 떠오름: "절반을 넘기면 오리가 둥실"
4. 100% 둥둥: "목표 달성! 오늘도 둥둥"
5. 기록 시트 (120ml / 250ml / 직접 입력): "한 번 탭으로 기록, 직접 입력도"

워치

1. 원형 화면 + 오리 + 기록 버튼 (캡션 없이 화면만)
